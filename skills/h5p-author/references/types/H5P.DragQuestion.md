# Drag and Drop (H5P.DragQuestion)

Words or pictures the learner drags onto drop zones: a word to its meaning, items into groups. Scored.

- Leave out every element's and zone's `x`, `y`, `width` and `height`: the build lays them out, the elements in rows above the zones, each as wide as its text, and makes the task as tall as they need.
- Write them only to put zones on a background picture (`question.settings.background`): `x` and `y` in percent of the task, `width` and `height` in em, the task being `size.width` / 16 em across (38.75 at 620 px). Look at the picture to place them; the preview shows where they landed.
- An element's `type` is H5P.AdvancedText for a word or H5P.Image for a picture. Its `dropZones` names every zone it may be dropped in, by place from `"0"`: name them all, since an element droppable only where it is right gives the answer away.
- A zone's `correctElements` names the elements right in it, the same way. A zone with no picture under it is told apart by its `label`, which the build shows: keep it to a few words, since a zone is as wide as its label.

## Example

```json
{
  "type": "H5P.DragQuestion",
  "params": {
    "question": {
      "task": {
        "elements": [
          { "type": { "library": "H5P.AdvancedText", "params": { "text": "<p>quiet</p>" } }, "dropZones": ["0", "1", "2"] },
          { "type": { "library": "H5P.AdvancedText", "params": { "text": "<p>enormous</p>" } }, "dropZones": ["0", "1", "2"] },
          { "type": { "library": "H5P.AdvancedText", "params": { "text": "<p>fragile</p>" } }, "dropZones": ["0", "1", "2"] }
        ],
        "dropZones": [
          { "label": "Making little noise", "correctElements": ["0"] },
          { "label": "Very large", "correctElements": ["1"] },
          { "label": "Easily broken", "correctElements": ["2"] }
        ]
      }
    }
  }
}
```

## Fields of H5P.DragQuestion 1.15

The example is `type` and `params` alone, and `params` holds the fields below. A source also names its own `title`, `language`, `license` and `authors`, all four required: the build refuses a source that leaves out any of them. Write the author and the licence the user gave, as given, and ask for neither: an author not given is the name you know the user by, or "Unknown"; a licence not given, or one no code below stands for, is `U`; never make up a name. A licence is one of these H5P codes: `U`, `CC BY`, `CC BY-SA`, `CC BY-ND`, `CC BY-NC`, `CC BY-NC-SA`, `CC BY-NC-ND`, `CC0 1.0`, `CC PDM`, `GNU GPL`, `PD`, `ODC PDDL`, `C`. Only the six CC BY codes take a version, written apart, one of 4.0, 3.0, 2.5, 2.0 or 1.0: "CC BY 4.0" is `"license": "CC BY", "licenseVersion": "4.0"`. `CC0 1.0` is one code, as it stands.
